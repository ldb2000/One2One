OneToOne — Architecture

Diagramme d'enchaînement des modules et des services. Base : 257 fichiers Swift, ~60 000 LOC. Généré le 10 août 2026.

Rendu des diagrammes : ce document utilise la syntaxe Mermaid (source en clair ci-dessous). Pour visualiser un diagramme rendu : cliquer sur Ouvrir dans Mermaid Live (ouvre mermaid.live avec le diagramme prérempli), ou coller la source dans VS Code (extension Mermaid Preview). Choix délibéré : pas de dépendance à un CDN JavaScript non signé (SRI) dans un document de doc interne.

Couleurs : voir légende ci-dessous.
  • Vues SwiftUI — composent l'UI, appellent les services.
  • Éditeur markdown — TextKit 1 natif, le markdown est la source de vérité.

  • Modèles SwiftData — persistance ; source unique de vérité des entités.

2. Pipeline transcription (réunion enregistrée)

flowchart LR
  Rec[AudioRecorderService enregistre .wav] --> Store[Meeting.wavFilePath]
  Store --> Diar[PyannoteDiarizer segments + embeddings]
  Store --> STT[STT Cohere ou local]
  Diar --> Match[SpeakerMatcher matching Collaborator]
  STT --> Aligner[TurnAligner.align merge par cluster]
  Match --> Canon[canonicalizeClusters 1 cluster canonique par collab]
  Aligner --> Canon
  Canon --> Persist[TranscriptSegment persistes]
  Persist --> Report[AIReportService.generate]
  Report --> Templating[ReportTemplating variables]
  Templating --> LLM[AIClient Claude/GPT/local]
  LLM --> Meeting[meeting.summary + report]

3. Pipeline génération rapport IA

flowchart TB
  UI[MeetingView bouton Generer] --> AIRS[AIReportService.generate]
  AIRS --> Template[ReportTemplate selectionne]
  Template --> Resolver[TemplateVariableResolver.resolveOne]
  Resolver -->|transcript| TB1[TranscriptTextBuilder + marqueurs IMPORTANT]
  Resolver -->|transcript.highlights| TH[TranscriptHighlightsBuilder]
  Resolver -->|collab.projects_context| PC1[ProjectsContextBuilder.build]
  Resolver -->|team.projects_context| PC2[ProjectsContextBuilder.buildForTeam]
  Resolver -->|historique_n| Hist[HistoryContextBuilder]
  Resolver -->|participants| Meta[Meeting props]
  AIRS --> Prompt[Prompt final]
  Prompt --> Fallback[Fallback append si placeholder absent]
  Fallback --> LLM[AIClient.stream]
  LLM --> Save[meeting.summary/report]
  Save --> ReportHTML[ReportHTMLBuilder]
  ReportHTML --> UI2[Onglet Rapport]
